# Intégration Niche Finder

Cette intégration est facultative. Elle ajoute **Save outlier** dans le menu `+` des cartes vidéo et envoie la vidéo dans l’Inbox.

L’installation automatique n’est autorisée que si le contrôle préalable trouve :

- une page Niche Finder enregistrée dans Agentic OS ;
- des cartes `.niche-card` ;
- un menu `.add-drop` ;
- un lien YouTube présent dans chaque carte ;
- `AgentOS.api` et `AgentOS.toast`.

Si ces contrats diffèrent, l’IA doit décrire l’adaptation et obtenir l’accord de l’utilisateur avant de modifier quoi que ce soit. L’absence de Niche Finder ne bloque jamais l’Outlier Bank.
